# CLAUDE.md: Cosmic Shore Screensaver

A standalone, lightweight screensaver of the Cosmic Shore Home screen (the lava lamp), built on the web path
(three.js) for a Windows `.scr`, a macOS `.saver` and a live preview on the landing page. The plan, decisions and
milestones are in `docs/PHASE1_ASSESSMENT_AND_PLAN.md`; read it before any work here. Caleb decides.

## The game repo is the reference, never a dependency

The game is `froglet-studio/Cosmic-Shore` (branch `bleeding-edge`). In a Claude project thread it is cloned beside
this repo at `../Cosmic-Shore`; on a computer, clone it there. Rules:

- **Nothing at runtime reads it.** Exporters under `tools/export/` read it offline and commit their output here.
- **Do not change it.** The one allowed exception, later, is an optional in-game screensaver mode.
- Its `CLAUDE.md` and team rules govern work **in that repo**, not here.

## Read the game's docs before visual work

Its skills (`/reorient`, `/flora`, `/fauna`, `/vessel-model`, ...) are not loaded in this repo. Read their files as
documents instead. The ones that matter here:

| Topic | Read in `../Cosmic-Shore/` |
|---|---|
| The Home screen itself | `Docs/claude/MENU_AND_LAVA_LAMP.md` |
| Colours: live colour set, what each field paints | `Docs/PALETTE.md`, `Docs/VesselModels/COLOR.md`, `Docs/VesselModels/COLOR_DOMAINS.md` |
| The Garland world and its flora and fauna | `Docs/ECOSYSTEM.md` §48, `.claude/skills/flora/SKILL.md`, `.claude/skills/fauna/SKILL.md` |
| A hull (Squirrel, Manta, Serpent) | `Docs/VesselModels/<Hull>.md` |
| Shaders and the rule that nothing in the world looks flat | `Docs/claude/SHADERS_AND_PERFORMANCE.md` |

`/reorient` is the game repo's "merge `bleeding-edge` into my branch and re-plan" step. It does not fit this repo,
which never merges the game. Its counterpart here is the **parity check**.

## Parity with the game's look (required)

Run the parity check (`parity/PARITY.md`, skill `.claude/skills/parity-check/SKILL.md`):

1. at the start of any visual work,
2. at every milestone, before its PR,
3. before every release, where it must report nothing that needs attention against the latest `bleeding-edge`.

```bash
git -C ../Cosmic-Shore fetch origin bleeding-edge && git -C ../Cosmic-Shore checkout origin/bleeding-edge
python3 tools/parity/check.py --game-repo ../Cosmic-Shore
```

`src/palette.ts` is generated by `tools/export/export_palette.py` from the colour set the game paints with. Never
edit it by hand. A new piece copied from the game gets a row in `parity/sources.json` in the same PR.
