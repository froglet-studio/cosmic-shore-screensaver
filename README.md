# Cosmic Shore Screensaver

A standalone, lightweight screensaver of the Cosmic Shore Home screen: vessels chasing the Omni crystal
through the Garland garden. It runs with no game, no Unity, no account and no network.

**Status:** Phase 1, assessment and plan. Read [docs/PHASE1_ASSESSMENT_AND_PLAN.md](docs/PHASE1_ASSESSMENT_AND_PLAN.md).

Targets, in order: Windows `.scr`, macOS `.saver`, then a browser/Linux ambient page. Distributed from
www.froglet.games.
